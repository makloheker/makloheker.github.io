Dokumen HTML Standar

Setiap dokumen HTML memiliki struktur dasar wajib agar dapat dibaca dan dirender dengan benar oleh web browser.

Berikut adalah susunan dokumen HTML5 standar:

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Judul Halaman Web</title>
</head>
<body>
    <h1>Selamat Datang di Website Saya</h1>
    <p>Ini adalah paragraf pertama saya di HTML.</p>
</body>
</html>

Penjelasan Bagian-Bagian HTML

1. <!DOCTYPE html>

Deklarasi ini memberitahu browser bahwa dokumen ini menggunakan standar HTML5. Deklarasi harus ditempatkan di baris paling atas dokumen sebelum tag apa pun.

2. <html lang="id">

Tag utama (root element) yang membungkus seluruh konten HTML. Atribut lang="id" menunjukkan bahwa bahasa utama konten halaman web adalah bahasa Indonesia (id).

3. Bagian <head>

Bagian ini berisi metadata atau informasi tentang dokumen web yang tidak langsung terlihat di halaman browser, antara lain:

  • <meta charset="UTF-8">: Menentukan pengkodean karakter dokumen (UTF-8 mendukung hampir semua huruf dan simbol dunia).
  • <meta name="viewport" content="width=device-width, initial-scale=1.0">: Mengatur agar tampilan web responsif di perangkat seluler/mobile.
  • <title>: Menentukan judul halaman yang akan tampil di tab browser.

4. Bagian <body>

Bagian ini berisi konten utama yang akan dilihat oleh pengunjung website, seperti teks, gambar, link, tabel, form, dan elemen visual lainnya.

Ringkasan

  • Setiap file HTML harus disimpan dengan ekstensi .html (contoh: index.html).
  • Struktur terpisah menjadi dua bagian utama: <head> (informasi/metadata) dan <body> (tampilan visual).
